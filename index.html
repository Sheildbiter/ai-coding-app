    Build an agent

    Brain free

    Get a free key (no credit card) at Google AI Studio — sign in, tap “Create API key”. Ask a parent first if you're under 18. Free tier is roughly 10–15 questions a minute. Your key stays in this tab only: it is never saved, and this page has no server to send it to. ChatGPT's API has no free tier — it needs money on the account.

    Test chat — Scout

    Talk to your agent. Anything you trained it on in the Training Lab, it can answer here.

    Try: “hello”, “who are you”, “what can you do” — then teach it something new and ask again.

    Teach your agent

    Training starts with examples. Write a question and the answer your agent should give. Add a few, then press Train — the examples move into the agent's memory, and you can test it in the Agent Builder chat.

      Google Colab ↗

      Free GPU notebooks in your browser — the real place beginners fine-tune small models. Free hours are limited and sessions time out.

      Hugging Face ↗

      Free models, datasets, and demo spaces — including the 3D model AIs. Free tier has queues and small hardware; big training is paid.

      Kaggle Notebooks ↗

      Free weekly GPU time with datasets built in. Good next step after Colab. The honest rule everywhere: free training is real, but it is small and slow — nobody gives away unlimited GPU time.

      Free helper agents

      Three small agents that work on whichever file is open in the Code Studio. Free, instant, and they run right here — no key, no account.

      Lens — the explainer

      Reads your open file and explains in plain words what it does: its size, its functions, its loops and decisions.

      Radar — the bug hunter

      Scans your open file for common trouble: unbalanced brackets, loose == comparisons, old-style var, forgotten TODOs, and very long lines.

      Press — the brief maker

      Paste a long, wordy message below and Press squeezes out the filler words, so the same instructions fit in far fewer characters — the trick that makes agent briefs cheap.

      Helper output lands here. Open a file in the Code Studio first — Lens and Radar work on that file.

      Compressed brief maker

      Agents work best from short briefs: the task, the outcome, the do's and don'ts, the facts, and when to stop. Fill in what you have — empty lines are skipped — and copy the result into any agent chat.
